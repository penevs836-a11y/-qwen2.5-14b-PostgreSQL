ИИ-Аналитик по покупкам (C# + Ollama + PostgreSQL)

Консольное приложение на C# для анализа цен в магазинах с использованием локальной нейросети Qwen2.5:14b (через Ollama) и реляционной базы данных PostgreSQL.

Функционал
- Выборка данных о ценах из PostgreSQL.
- Передача точечного контекста товаров в локальную LLM.
- Генерация аналитического отчета нейросетью по самым выгодным позициям.
- Фиксация логов диалога и истории запросов обратно в БД.

 Стек технологий
- Язык: C# (.NET 8.0)
- База данных: PostgreSQL (Npgsql)
- ИИ: Ollama (Модель`qwen2.5:14b`)

 Настройка и запуск
1. Разверните структуру БД из файла `Script-1.sql`.
2. Укажите ваши данные подключения в `ConnectionString` внутри кода.
3. Убедитесь, что Ollama запущена локально с моделью `qwen2.5:14b`.

 Известные проблемы (В процессе исправления)
- Фильтрация контекста: В текущей версии присутствует баг в модуле парсинга строки пользователя (Шаг 1). Ключевое слово для SQL-запроса передается пустым, из-за чего ИИ получает избыточный контекст (всю базу товаров). Логика извлечения точечного ключевого слова находится в процессе рефакторинга.
